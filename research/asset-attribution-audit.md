### B. `assets/fonts/main.ttf` — **🚨 HIGH: Calibri (proprietary Microsoft font, NOT redistributable)**

- **Location:** `assets/fonts/main.ttf` (1,650,632 bytes / ~1.65 MB)
- **Code reference:** `core/src/main/kotlin/com/sohai/platformer/FontManager.kt:38` — `internal const val FONT_PATH = "fonts/main.ttf"`. **Actively loaded by every screen via `FontManager.getShared(size)`.**
- **Declared in NOTICE.md:** **NO.** NOTICE.md does not mention `assets/fonts/main.ttf` at all.
- **Identified font (from TTF name-table strings extracted from the binary):**
  - Family name: **Calibri**
  - Subfamily: **Regular**
  - Manufacturer: **Microsoft**
  - Designer credit: **Luc(as) de Groot**
  - Version: **6.27**
  - Copyright string present in font: contains "© Microsoft Corporation. All Rights Reserved."
- **License text inside the font binary (verbatim):**
  > "Microsoft supplied font. You may use this font to create, display, and print content as permitted by the license terms or terms of use, of the Microsoft product, service, or content in which this font was included. **You may only (i) embed this font in content as permitted by the embedding restrictions included in this font, and (ii) temporarily download this font to a printer or other output device to help print content. Any other use is prohibited.**"
- **Git provenance:** Commit `c056d40` (2026-05-09) — "Add Calibri font asset and fix unnecessary lateinit warning" — explicitly identifies the asset as Calibri in the commit message. Author: Sohail Shah, co-authored by Claude Sonnet 4.6.

#### Why this is a HARD legal blocker for alpha

1. Calibri is bundled with Microsoft Windows, Office, and certain Microsoft developer tooling. The Microsoft Typography license [explicitly does NOT grant general redistribution rights](https://learn.microsoft.com/en-us/typography/fonts/font-faq). Redistribution requires a separate licensing arrangement with Microsoft (or, in some cases, Ascender Corp. which originally produced the font).
2. The repository is **public on GitHub**. Bundling the font in a public repo is itself a redistribution event, distinct from shipping a binary.
3. The proprietary `LICENSE` in this repo explicitly carves out third-party assets via NOTICE.md — but Calibri is NOT in NOTICE.md, and even if it were added, the Microsoft font license does NOT grant rights compatible with public hosting + alpha distribution. Adding a NOTICE entry would document the problem, not fix it.
4. The proprietary game license (Calibri's "permitted by the license terms... of the Microsoft product... in which this font was included") only flows through products that legitimately shipped Calibri (Windows, Office). Cloudy Ninja is neither.
5. itch.io alpha distribution would expose the user to a takedown / license-violation claim. Steam release would compound it.

#### Severity classification

**HIGH (category (a): used asset, no attribution / category (c): license requires more than NOTICE.md can provide — actually requires removal & replacement, not attribution at all).** This is the singular alpha-blocking finding of this audit.

#### Recommended remediation (NOT executed in this PR — research-only)

Replace `assets/fonts/main.ttf` with a font under a permissive license. Candidates that match a "modern sans serif with pixel-friendly rendering" brief and are well-suited for libGDX `FreeTypeFontGenerator`:

| Candidate | License | Notes |
|---|---|---|
| **Inter** (Rasmus Andersson) | SIL OFL 1.1 | Excellent screen rendering; closest visual match to Calibri among permissively-licensed sans-serifs. Already widely used in indie games. |
| **Source Sans 3** (Adobe) | SIL OFL 1.1 | Strong open-source pedigree. |
| **Open Sans** (Steve Matteson) | SIL OFL 1.1 | The standard "safe" choice. |
| **Atkinson Hyperlegible** (Braille Institute) | SIL OFL 1.1 | Accessibility-optimized — would also strengthen the existing color-blind / reduced-motion accessibility story. |

Whichever is chosen, the SIL OFL 1.1 license requires:
- Bundling a copy of the OFL license text alongside the font file (no in-game visible credit required).
- Optionally a `Reserved Font Name` if the font is renamed (not relevant here — keep the canonical name).
- Adding an entry to NOTICE.md.

**A `QUESTIONS.md` entry has been filed (see below) to get the user's pick before the alpha branch is cut.**

- **Not file-as-QUESTIONS.md-entry-worthy:** functionally unused + tiny + trivial-to-remediate. Flagging in the audit is sufficient — the user can decide between (1) and (2) at NOTICE.md update time. **MEDIUM not HIGH because the asset is not actually loaded by any code path.**
